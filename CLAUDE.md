# Ayastefanos Utancı

A Godot project whose lore lives in the Obsidian vault `Lore/`.

**Before answering any question about the lore, the books or the vault, read `Lore/Handbook.md` and follow it.** The vault's rules are in `Lore/Rules.md`:
- Answer only from the books in `Lore/Converted/` and the notes built on them. The web is used only when the user explicitly asks, and it is marked ⚠ Not from vault sources.
- Cite every claim with a page link, and name the author's side.

Tools for the vault (conversion, OCR, mentions, link checks, images) are in `tools/`; the handbook explains them. The user writes in Turkish; answer in Turkish unless asked otherwise.
